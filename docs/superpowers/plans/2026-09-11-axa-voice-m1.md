# axa-voice M1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Speak to Claude and hear it answer within ~1.3 s, on open speakers, interruptible mid-sentence.

**Architecture:** Eight components behind the interfaces in §3 of the spec. Seven are deliberately simple; a single-threaded Director holds all the logic. Audio capture, playback and echo cancellation live in one Swift helper process that Node drives over pipes. Speech-to-text is a local whisper.cpp server; text-to-speech is Cartesia over a WebSocket; Claude runs as one long-lived Agent SDK session.

**Tech Stack:** TypeScript on Node 22 (native type stripping — no build step), `node:test`, `@anthropic-ai/claude-agent-sdk`, Swift 6 / AudioToolbox, whisper.cpp 1.9.2, Cartesia.

**Spec:** `docs/superpowers/specs/2026-09-11-voice-agent-design.md` — read it before Task 1. Every design decision below is argued there, and the measured numbers this plan asserts on come from its §4.

## Global Constraints

- **Node ≥ 22.18.** Type stripping is unflagged from this version, so `.ts` files run directly via `node`. No bundler, no build step, no `dist/`.
- **ESM only.** `@anthropic-ai/claude-agent-sdk` ships ESM. `"type": "module"` in `package.json`.
- **Audio unit sample rate: 24 000 Hz, mono, PCM16, both scopes.** Not negotiable — VoiceProcessingIO fails `AudioUnitInitialize` with `-10875` on mismatched client rates (spec §3).
- **Frames above the helper: 16 000 Hz, mono, PCM16, 320 samples (20 ms).** `AudioFrame = Int16Array`.
- **`MaximumFramesPerSlice` stays at 512.** Raising it batches render callbacks into 85 ms blocks and breaks barge-in (spec §6).
- **Never gate startup on `AVCaptureDevice.requestAccess`.** It can never call back (spec §6).
- **Latency assertions measure turn N, never turn 1.** Turn 1 includes startup cost and reports ~7 s (spec §4).
- **No secret ever reaches a log line or a commit.** Keys come from `.env`, which is gitignored.
- **Italian is the interaction language**; identifiers and comments in code are English.

```
  *.test.ts                   one per source file, plus integration tests
```

Rationale for the splits that are not obvious:

- **`audio/protocol.ts` is separate from `audio/device.ts`** so the framing can be tested
  exhaustively without spawning a process or touching a microphone. Framing bugs are
  otherwise diagnosed through an audio device, which is miserable.
- **`stt/clean.ts` and `director/approval.ts` are pure functions in their own files.** Both
  are security-relevant (spec §8: a hallucination reaching the approval grammar is the
  failure mode the fail-closed rule exists to stop) and both deserve dense table-driven
  tests with no I/O.
- **`config.ts` holds every tunable.** The measured constants — 350 ms partial cadence,
  250/700 ms turn thresholds, 1200 ms filler, 10 s approval timeout — are design outputs,
  not magic numbers scattered through call sites.

The helper's protocol (already implemented in `proto/native/aecio.swift`): **stdin** takes

mono with no framing; **stderr** is one JSON object per line.

```typescript
  assert.equal(p.push(Buffer.alloc(1000)).length, 1);
  // 140 more samples completes the second frame exactly.
  assert.equal(p.push(Buffer.alloc(280)).length, 1);
  assert.equal(p.push(Buffer.alloc(0)).length, 0);
});

test('PcmParser preserves sample values across a split boundary', () => {
  const p = new PcmParser(2);
  const first = Buffer.alloc(3);      // 1.5 samples: odd byte count
  first.writeInt16LE(-12345, 0);
  first[2] = 0x39;
  const second = Buffer.from([0x30]); // completes sample 2 as 0x3039 = 12345
  assert.deepEqual(p.push(first), []);
  const frames = p.push(second);
  assert.equal(frames.length, 1);
  assert.equal(frames[0]![0], -12345);
  assert.equal(frames[0]![1], 12345);
```

The last test matters: stdout is a byte stream with no framing, so a frame boundary can
land mid-sample. A parser that assumes even-length chunks corrupts audio in a way that
sounds like noise and looks like a hardware fault.

```typescript
import type { AudioFrame } from '../types.ts';

export type HelperEvent =
  | { type: 'ready'; rate: number; micRate: number }
  | { type: 'aec'; enabled: boolean }
  | { type: 'stats'; renderMaxGapMs: number; playRingMs: number; framesConsumed: number }
  | { type: 'flushed'; seq: number; heardMs: number; consumedMs: number; renderReactionMs: number }
  | { type: 'overflow' }
  | { type: 'error'; message: string }
  | { type: 'stopped' }
  | { type: 'malformed'; raw: string };

export function encodeCommand(cmd: 'A' | 'F' | 'Q', payload?: Buffer): Buffer {
  const body = payload ?? Buffer.alloc(0);
  const header = Buffer.alloc(5);
  header.write(cmd, 0, 'ascii');
  header.writeUInt32LE(body.length, 1);
  return Buffer.concat([header, body]);
}

/** Line-delimited JSON on stderr, tolerant of arbitrary chunk boundaries. */
export class EventParser {
  #buffer = '';

  push(chunk: Buffer): HelperEvent[] {
    this.#buffer += chunk.toString('utf8');
    const events: HelperEvent[] = [];
    let index: number;
    while ((index = this.#buffer.indexOf('\n')) >= 0) {
      const line = this.#buffer.slice(0, index).trim();
      this.#buffer = this.#buffer.slice(index + 1);
      if (!line) continue;
      try {
        events.push(JSON.parse(line) as HelperEvent);
      } catch {
        // Never swallow: an unparseable line means the helper is misbehaving,
        // and a silent drop here looks like a dead microphone (spec §9).
        events.push({ type: 'malformed', raw: line });
      }
    }
    return events;
  }
}

/** Raw PCM16LE with no framing; chunk boundaries may split a sample. */
export class PcmParser {
  #carry = Buffer.alloc(0);
  readonly #bytesPerFrame: number;

  constructor(samplesPerFrame: number) {
    this.#bytesPerFrame = samplesPerFrame * 2;
  }

  push(chunk: Buffer): AudioFrame[] {
    let data = this.#carry.length ? Buffer.concat([this.#carry, chunk]) : chunk;
    const frames: AudioFrame[] = [];
    let offset = 0;
    while (data.length - offset >= this.#bytesPerFrame) {
      const frame = new Int16Array(this.#bytesPerFrame / 2);
      for (let i = 0; i < frame.length; i++) {
        frame[i] = data.readInt16LE(offset + i * 2);
      }
      frames.push(frame);
      offset += this.#bytesPerFrame;
    }
    this.#carry = Buffer.from(data.subarray(offset));
    return frames;
  }
}
```

Then read `native/aecio.swift` end to end before changing anything. The four things that

1. Both client scopes must be set to the **same** sample rate (bus 1 / Output for mic,

2. `MaximumFramesPerSlice` stays **512**.

4. `AudioUnitSetProperty` returns `noErr` for formats the unit will later reject — only
   `AudioUnitInitialize`'s return value is meaningful.

- [ ] **Step 3: Add the silence watchdog**

The copied helper does not have it. A TCC denial delivers digital silence, which is
indistinguishable from a quiet room, so without this the app listens to nothing forever
(spec §6).

In the writer thread, track consecutive all-zero samples and emit an error once ~2 s have
passed with no non-zero sample:

```swift
// Watchdog: TCC denial yields pure digital silence, which looks exactly like
// a quiet room. Two seconds of EXACT zeros is not a quiet room.
private var zeroRun = 0
private let zeroRunLimit: Int          // set to micRate * 2
private var watchdogFired = false

func observe(_ samples: UnsafeBufferPointer<Int16>) {
    var sawNonZero = false
    for s in samples where s != 0 { sawNonZero = true; break }
    if sawNonZero {
        zeroRun = 0
    } else {
        zeroRun += samples.count
        if zeroRun >= zeroRunLimit && !watchdogFired {
            watchdogFired = true
            emit(["type": "error",
                  "message": "microphone delivered only digital silence for 2s — check microphone permission"])
        }
    }
}
```

```typescript
import { spawn, type ChildProcess } from 'node:child_process';
import type { AudioFrame, AudioInput, AudioOutput, Unsubscribe } from '../types.ts';
import type { Config } from '../config.ts';
import { encodeCommand, EventParser, PcmParser } from './protocol.ts';

export class AudioDevice implements AudioInput, AudioOutput {
  readonly #config: Config;
  readonly #spawnFn: typeof spawn;
  #proc: ChildProcess | undefined;
  #frameHandlers = new Set<(f: AudioFrame) => void>();
  #errorHandlers = new Set<(m: string) => void>();
  #pendingFlushes = new Map<number, (r: { heardMs: number }) => void>();
  #flushSeq = 0;
  #queuedSamples = 0;

  constructor(config: Config, opts: { spawnFn?: typeof spawn } = {}) {
    this.#config = config;
    this.#spawnFn = opts.spawnFn ?? spawn;
  }

  async start(): Promise<void> {
    const { helperPath, deviceRate, frameRate, frameSamples } = this.#config.audio;
    const proc = this.#spawnFn(
      helperPath,
      ['--rate', String(deviceRate), '--mic-rate', String(frameRate)],
      { stdio: ['pipe', 'pipe', 'pipe'] },
    );
    this.#proc = proc;

    const pcm = new PcmParser(frameSamples);
    proc.stdout!.on('data', (chunk: Buffer) => {
      for (const frame of pcm.push(chunk)) {
        for (const handler of this.#frameHandlers) handler(frame);
      }
    });

    const events = new EventParser();
    return new Promise<void>((resolve, reject) => {
      const onExit = (code: number | null) =>
        reject(new Error(`audio helper exited with code ${code} before becoming ready`));
      proc.once('exit', onExit);

      proc.stderr!.on('data', (chunk: Buffer) => {
        for (const event of events.push(chunk)) {
          switch (event.type) {
            case 'ready':
              proc.off('exit', onExit);
              proc.once('exit', (code) =>
                this.#fail(`audio helper exited unexpectedly with code ${code}`));
              resolve();
              break;
            case 'flushed': {
              this.#pendingFlushes.get(event.seq)?.({ heardMs: event.heardMs });
              this.#pendingFlushes.delete(event.seq);
              break;
            }
            case 'error':
              this.#fail(event.message);
              break;
            case 'malformed':
              this.#fail(`audio helper emitted an unparseable line: ${event.raw}`);
              break;
            default:
              break;
          }
        }
      });
    });
  }

  async stop(): Promise<void> {
    const proc = this.#proc;
    if (!proc) return;
    proc.stdin!.write(encodeCommand('Q'));
    this.#proc = undefined;
    await new Promise<void>((resolve) => {
      const timer = setTimeout(() => { proc.kill(); resolve(); }, 500);
      proc.once('exit', () => { clearTimeout(timer); resolve(); });
    });
  }

  onFrame(cb: (frame: AudioFrame) => void): Unsubscribe {
    this.#frameHandlers.add(cb);
    return () => this.#frameHandlers.delete(cb);
  }

  onError(cb: (message: string) => void): Unsubscribe {
    this.#errorHandlers.add(cb);
    return () => this.#errorHandlers.delete(cb);
  }

  enqueue(frame: AudioFrame): void {
    const proc = this.#proc;
    if (!proc) return;
    const payload = Buffer.alloc(frame.length * 2);
    for (let i = 0; i < frame.length; i++) payload.writeInt16LE(frame[i]!, i * 2);
    proc.stdin!.write(encodeCommand('A', payload));
    this.#queuedSamples += frame.length;
  }

  async flush(): Promise<{ heardMs: number }> {
    const proc = this.#proc;
    if (!proc) return { heardMs: 0 };
    const seq = ++this.#flushSeq;
    this.#queuedSamples = 0;
    const settled = new Promise<{ heardMs: number }>((resolve) => {
      this.#pendingFlushes.set(seq, resolve);
    });
    proc.stdin!.write(encodeCommand('F'));
    return settled;
  }

  isPlaying(): boolean {
    return this.#queuedSamples > 0;
  }

  #fail(message: string): void {
    for (const handler of this.#errorHandlers) handler(message);
  }
}
```

```typescript
/**
 * Whisper emits confident text for silence. Silero VAD at the server stops most
 * of it (spec §8), but a cough or a keyboard clack still reaches the decoder and
 * still becomes a sentence, so this runs on every transcript.
 *
 * Rule that must not be "simplified": the length test is on CHARACTERS, never on
 * words. "sì", "no" and "ferma" are the entire approval vocabulary (spec §8) and
 * a minimum word count would silently delete them.
 */
const BRACKETED = /[\[\(\*][^\])*]*[\])\*]/g;
const SUBTITLE_BOILERPLATE = /sottotitoli.*$/gis;
const THANKS_BOILERPLATE = /^\s*grazie(\s+per\s+la\s+visione)?\s*!?\s*$/i;
const TRAILING_PUNCTUATION = /[.,;:!?…\s]+$/;

export function clean(raw: string): string {
  const text = raw
    .replace(BRACKETED, ' ')
    .replace(SUBTITLE_BOILERPLATE, ' ')
    .replace(TRAILING_PUNCTUATION, '')
    .replace(/\s+/g, ' ')
    .trim();

  if (THANKS_BOILERPLATE.test(text)) return '';
  return text.length < 2 ? '' : text;
}
```

```typescript
import { spawn, type ChildProcess } from 'node:child_process';
import { createConnection } from 'node:net';
import { access } from 'node:fs/promises';
import type { Config } from '../config.ts';

const VAD_MODEL_URL =
  'https://huggingface.co/ggml-org/whisper-vad/resolve/main/ggml-silero-v5.1.2.bin';

async function portIsFree(port: number): Promise<boolean> {
  return new Promise((resolve) => {
    const socket = createConnection({ port, host: '127.0.0.1' })
      .on('connect', () => { socket.destroy(); resolve(false); })
      .on('error', () => resolve(true));
  });
}

export async function preflight(config: Config): Promise<void> {
  const { modelPath, vadModelPath, port } = config.stt;

  await access(modelPath).catch(() => {
    throw new Error(
      `whisper model not found at ${modelPath}. Download ggml-small.bin from ` +
        'https://huggingface.co/ggerganov/whisper.cpp',
    );
  });

  await access(vadModelPath).catch(() => {
    throw new Error(
      `Silero VAD model not found at ${vadModelPath}. Download it (885 KB) from ` +
        `${VAD_MODEL_URL}\nRefusing to start without it: without VAD, whisper turns ` +
        'silence into confident sentences and the agent answers questions nobody asked.',
    );
  });

  if (!(await portIsFree(port))) {
    throw new Error(
      `port ${port} is already in use. macOS lets a second whisper-server bind the ` +
        'same port and then splits requests between them, so transcripts come from an ' +
        'unpredictable model. Stop the other process before starting.',
    );
  }
}

export class WhisperServer {
  readonly url: string;
  readonly #config: Config;
  #proc: ChildProcess | undefined;

  constructor(config: Config) {
    this.#config = config;
    this.url = `http://127.0.0.1:${config.stt.port}`;
  }

  async start(): Promise<void> {
    await preflight(this.#config);
    const { port, modelPath, vadModelPath, language } = this.#config.stt;

    this.#proc = spawn(
      'whisper-server',
      [
        '-m', modelPath,
        '--port', String(port),
        '--host', '127.0.0.1',
        '-l', language,
        '--vad',
        '--vad-model', vadModelPath,
      ],
      { stdio: ['ignore', 'ignore', 'pipe'] },
    );

    const deadline = Date.now() + 20_000;
    for (;;) {
      if (Date.now() > deadline) {
        await this.stop();
        throw new Error('whisper-server did not become healthy within 20s');
      }
      try {
        const res = await fetch(`${this.url}/health`);
        if (res.ok) return;
      } catch {
        // Not up yet. The loop's deadline is the only exit.
      }
      await new Promise((r) => setTimeout(r, 200));
    }
  }

  async stop(): Promise<void> {
    const proc = this.#proc;
    if (!proc) return;
    this.#proc = undefined;
    proc.kill();
    await new Promise<void>((resolve) => {
      const timer = setTimeout(() => { proc.kill('SIGKILL'); resolve(); }, 2000);
      proc.once('exit', () => { clearTimeout(timer); resolve(); });
    });
  }
}
```

```typescript
import type {
  AudioFrame, Transcriber, TranscriptionStream, Unsubscribe,

/** whisper-server rejects raw PCM; the payload must be a container. */
export function encodeWav(samples: Int16Array, rate: number): Buffer {
  const dataBytes = samples.length * 2;
  const buffer = Buffer.alloc(44 + dataBytes);
  buffer.write('RIFF', 0, 'ascii');
  buffer.writeUInt32LE(36 + dataBytes, 4);
  buffer.write('WAVE', 8, 'ascii');
  buffer.write('fmt ', 12, 'ascii');
  buffer.writeUInt32LE(16, 16);           // fmt chunk size
  buffer.writeUInt16LE(1, 20);            // PCM
  buffer.writeUInt16LE(1, 22);            // mono
  buffer.writeUInt32LE(rate, 24);
  buffer.writeUInt32LE(rate * 2, 28);     // byte rate
  buffer.writeUInt16LE(2, 32);            // block align
  buffer.writeUInt16LE(16, 34);           // bits per sample
  buffer.write('data', 36, 'ascii');
  buffer.writeUInt32LE(dataBytes, 40);
  for (let i = 0; i < samples.length; i++) buffer.writeInt16LE(samples[i]!, 44 + i * 2);
  return buffer;
}

export class WhisperTranscriber implements Transcriber {
  readonly #config: Config;
  readonly #fetchFn: typeof fetch;

  constructor(config: Config, opts: { fetchFn?: typeof fetch } = {}) {
    this.#config = config;
    this.#fetchFn = opts.fetchFn ?? fetch;
  }

  async open(): Promise<TranscriptionStream> {
    return new WhisperStream(this.#config, this.#fetchFn);
  }
}

class WhisperStream implements TranscriptionStream {
  readonly #config: Config;
  readonly #fetchFn: typeof fetch;
  readonly #partialHandlers = new Set<(t: string) => void>();
  readonly #finalHandlers = new Set<(t: string) => void>();
  #samples: number[] = [];
  #timer: NodeJS.Timeout;
  #busy = false;
  #closed = false;

  constructor(config: Config, fetchFn: typeof fetch) {
    this.#config = config;
    this.#fetchFn = fetchFn;
    this.#timer = setInterval(() => void this.#tick(), config.stt.partialCadenceMs);
  }

  push(frame: AudioFrame): void {
    if (this.#closed) return;
    for (const sample of frame) this.#samples.push(sample);
  }

  onPartial(cb: (text: string) => void): Unsubscribe {
    this.#partialHandlers.add(cb);
    return () => this.#partialHandlers.delete(cb);
  }

  onFinal(cb: (text: string) => void): Unsubscribe {
    this.#finalHandlers.add(cb);
    return () => this.#finalHandlers.delete(cb);
  }

  async close(): Promise<void> {
    if (this.#closed) return;
    this.#closed = true;
    clearInterval(this.#timer);
    // Wait out an in-flight partial: the server serializes, so racing it would
    // only make the final transcript slower (spec §5).
    while (this.#busy) await new Promise((r) => setTimeout(r, 10));
    const text = await this.#transcribe(0);
    if (text) for (const handler of this.#finalHandlers) handler(text);
  }

  async #tick(): Promise<void> {
    if (this.#busy || this.#closed || !this.#samples.length) return;
    const text = await this.#transcribe(this.#config.stt.partialAudioCtx);
    if (text && !this.#closed) {
      for (const handler of this.#partialHandlers) handler(text);
    }
  }

  async #transcribe(audioCtx: number): Promise<string> {
    if (!this.#samples.length) return '';
    this.#busy = true;
    try {
      const { port, language } = this.#config.stt;
      const wav = encodeWav(Int16Array.from(this.#samples), this.#config.audio.frameRate);

      const form = new FormData();
      form.set('file', new Blob([wav], { type: 'audio/wav' }), 'audio.wav');
      form.set('response_format', 'text');
      form.set('language', language);
      form.set('audio_ctx', String(audioCtx));

      const res = await this.#fetchFn(`http://127.0.0.1:${port}/inference`, {
        method: 'POST',
        body: form,
      });
      if (!res.ok) return '';
      return clean(await res.text());
    } catch {
      // A dropped partial is recoverable — the next tick sees the same audio.
      // The final transcription is the one that must not be lost, and close()
      // issues it separately.
      return '';
    } finally {
      this.#busy = false;
    }
  }
}
```

```typescript
import type { AudioFrame, TurnDetector, Unsubscribe } from '../types.ts';
import type { Config } from '../config.ts';

const SPEECH_RMS_THRESHOLD = 500;

/** Italian words that cannot end an utterance. */
const TRAILING_CONJUNCTIONS = new Set([
  'e', 'ed', 'o', 'oppure', 'ma', 'però', 'che', 'se', 'quando', 'mentre',
  'perché', 'con', 'di', 'da', 'per', 'in', 'su', 'tra', 'fra', 'il', 'la',
  'lo', 'un', 'una', 'del', 'della',
]);

/**
 * Whisper truncates or invents the last word of a growing buffer, so the tail of
 * a partial churns on every pass. Comparing whole strings therefore never
 * converges and the turn never ends (spec §5).
 */
export function stablePrefix(text: string, dropTokens: number): string {
  const tokens = text.trim().split(/\s+/).filter(Boolean);
  if (tokens.length <= dropTokens) return '';
  return tokens.slice(0, tokens.length - dropTokens).join(' ');
}

export function looksUnfinished(text: string): boolean {
  const tokens = text.trim().toLowerCase().replace(/[.,;:!?…]+$/, '').split(/\s+/);
  const last = tokens.at(-1);
  return last !== undefined && TRAILING_CONJUNCTIONS.has(last);
}

function rms(frame: AudioFrame): number {
  let sum = 0;
  for (const sample of frame) sum += sample * sample;
  return Math.sqrt(sum / Math.max(1, frame.length));
}

export class VadTurnDetector implements TurnDetector {
  readonly #config: Config;
  readonly #now: () => number;
  readonly #startHandlers = new Set<() => void>();
  readonly #endHandlers = new Set<() => void>();

  #speaking = false;
  #silenceSince: number | null = null;
  #lastPrefix = '';
  #prefixStableSince: number | null = null;

  constructor(config: Config, opts: { now?: () => number } = {}) {
    this.#config = config;
    this.#now = opts.now ?? Date.now;
  }

  push(frame: AudioFrame, partialText: string | null): void {
    const now = this.#now();
    const isSpeech = rms(frame) > SPEECH_RMS_THRESHOLD;

    if (isSpeech) {
      this.#silenceSince = null;
      if (!this.#speaking) {
        this.#speaking = true;
        for (const handler of this.#startHandlers) handler();
      }
    } else if (this.#speaking) {
      this.#silenceSince ??= now;
    }

    const prefix = stablePrefix(
      partialText ?? '',
      this.#config.turn.stablePrefixDropTokens,
    );
    if (prefix !== this.#lastPrefix) {
      this.#lastPrefix = prefix;
      this.#prefixStableSince = now;
    } else {
      this.#prefixStableSince ??= now;
    }

    if (!this.#speaking || this.#silenceSince === null) return;

    const unfinished = looksUnfinished(partialText ?? '');
    const required = unfinished
      ? this.#config.turn.unfinishedSilenceMs
      : this.#config.turn.silenceMs;

    if (now - this.#silenceSince >= required) this.#endTurn();
  }

  onSpeechStart(cb: () => void): Unsubscribe {
    this.#startHandlers.add(cb);
    return () => this.#startHandlers.delete(cb);
  }

  onTurnEnd(cb: () => void): Unsubscribe {
    this.#endHandlers.add(cb);
    return () => this.#endHandlers.delete(cb);
  }

  #endTurn(): void {
    this.#speaking = false;
    this.#silenceSince = null;
    this.#lastPrefix = '';
    this.#prefixStableSince = null;
    for (const handler of this.#endHandlers) handler();
  }
}
```

```typescript
import type { AgentEvent, SpeechFilter } from '../types.ts';

const CODE_FENCE = /```[\s\S]*?(```|$)/g;
const CODE_REPLACEMENT = " Te l'ho scritta, guarda lo schermo. ";

const EXTENSIONS: Record<string, string> = {
  ts: 'punto ti esse', js: 'punto gi esse', tsx: 'punto ti esse ics',
  md: 'punto emme di', json: 'punto geison', swift: 'punto swift',
};

/** Sentence end, tolerating a missing space before the next capital. */
const SENTENCE_END = /^([\s\S]*?[.!?…]["')\]]?)(\s+|(?=[A-ZÀ-Ý]))/;

export function toSpokenForm(text: string): string {
  return text
    .replace(/\*\*(.+?)\*\*/g, '$1')
    .replace(/\*(.+?)\*/g, '$1')
    .replace(/`([^`]+)`/g, '$1')
    .replace(/^\s*[-*]\s+/gm, '')
    .replace(/([\w.-]+\/)+([\w-]+)\.(\w+)/g, (_all, dirs: string, base: string, ext: string) => {
      const parent = dirs.split('/').filter(Boolean).at(-1);
      const spokenExt = EXTENSIONS[ext] ?? `punto ${ext}`;
      return parent ? `${base} ${spokenExt}, dentro ${parent}` : `${base} ${spokenExt}`;
    })
    .replace(/\b([\w-]+)\.(\w+)\b/g, (all, base: string, ext: string) =>
      EXTENSIONS[ext] ? `${base} ${EXTENSIONS[ext]}` : all)
    .replace(/\s+/g, ' ')
    .trim();
}

export class SentenceSpeechFilter implements SpeechFilter {
  async *filter(events: AsyncIterable<AgentEvent>): AsyncIterable<string> {
    let buffer = '';

    for await (const event of events) {
      if (event.type !== 'text') continue;
      buffer += event.delta;

      // Strip code before splitting: a fence contains punctuation that would
      // otherwise be spoken as sentences.
      buffer = buffer.replace(CODE_FENCE, CODE_REPLACEMENT);

      for (;;) {
        const match = SENTENCE_END.exec(buffer);
        if (!match) break;
        buffer = buffer.slice(match[0].length);
        const spoken = toSpokenForm(match[1]!);
        if (spoken) yield spoken;
      }
    }

    const tail = toSpokenForm(buffer.replace(CODE_FENCE, CODE_REPLACEMENT));
    if (tail) yield tail;
  }
}
```

```typescript
export type ApprovalAnswer = 'yes' | 'no' | 'unclear';

const YES = new Set([
  'sì', 'si', 'sisi', 'ok', 'okay', 'okey', 'vai', 'fallo', 'certo',
  'va bene', 'vabene', 'procedi', 'conferma', 'avanti', 'perfetto',
]);

const NO = new Set([
  'no', 'nono', 'ferma', 'fermati', 'stop', 'annulla', 'lascia stare',
  'lascia perdere', 'aspetta', 'non farlo', 'meglio di no',
]);

/**
 * Fail closed: only a short, unambiguous utterance counts as consent.
 *
 * Deliberately NOT a substring search. "non so se sì o no" contains "sì", and
 * approving it would write a file the user never asked for. The whole utterance
 * must be the answer — anything longer is a new turn, not a confirmation (spec §8).
 */
export function interpretApproval(text: string): ApprovalAnswer {
  const normalised = text
    .toLowerCase()
    .replace(/[.,;:!?…]/g, '')
    .replace(/\s+/g, ' ')
    .trim();

  if (!normalised) return 'unclear';
  if (YES.has(normalised)) return 'yes';
  if (NO.has(normalised)) return 'no';
  return 'unclear';
}
```

```typescript
import { randomUUID } from 'node:crypto';
import type { AudioFrame, Voice } from '../types.ts';
import type { Config } from '../config.ts';

interface CartesiaMessage {
  type: 'chunk' | 'done' | 'error';
  data?: string;
  message?: string;
  title?: string;
}

export class CartesiaVoice implements Voice {
  readonly #config: Config;
  readonly #connect: (url: string) => WebSocket;

  constructor(config: Config, opts: { connect?: (url: string) => WebSocket } = {}) {
    this.#config = config;
    this.#connect = opts.connect ?? ((url) => new WebSocket(url));
  }

  async *synthesize(
    text: AsyncIterable<string>,
    signal: AbortSignal,
  ): AsyncIterable<AudioFrame> {
    const { apiVersion, model, voiceId, language } = this.#config.voice;
    const url =
      `wss://api.cartesia.ai/tts/websocket` +
      `?cartesia_version=${apiVersion}` +
      `&api_key=${encodeURIComponent(this.#config.cartesiaKey())}`;

    const socket = this.#connect(url);
    const contextId = randomUUID();
    const queue: AudioFrame[] = [];
    let done = false;
    let failure: Error | undefined;
    let wake: (() => void) | undefined;

    const notify = () => { wake?.(); wake = undefined; };
    const finish = (err?: Error) => { failure ??= err; done = true; notify(); };

    socket.addEventListener('message', (event) => {
      const message = JSON.parse((event as MessageEvent).data as string) as CartesiaMessage;
      if (message.type === 'chunk' && message.data) {
        const bytes = Buffer.from(message.data, 'base64');
        // Base64 can split a sample only at chunk boundaries Cartesia controls;
        // it always sends whole samples, so an odd length means corruption.
        const frame = new Int16Array(bytes.length >> 1);
        for (let i = 0; i < frame.length; i++) frame[i] = bytes.readInt16LE(i * 2);
        queue.push(frame);
        notify();
      } else if (message.type === 'done') {
        finish();
      } else if (message.type === 'error') {
        // Never interpolate the URL: it carries the API key.
        finish(new Error(`Cartesia: ${message.message ?? message.title ?? 'unknown error'}`));
      }
    });
    socket.addEventListener('close', () => finish());
    socket.addEventListener('error', () => finish(new Error('Cartesia: connection failed')));

    const onAbort = () => { try { socket.close(); } catch { /* already closed */ } finish(); };
    signal.addEventListener('abort', onAbort, { once: true });

    const opened = new Promise<void>((resolve) => {
      socket.addEventListener('open', () => resolve(), { once: true });
    });

    // Feed sentences as they arrive; this is what lets audio start before the
    // model has finished writing (spec §4).
    const feeding = (async () => {
      await opened;
      let last: string | undefined;
      for await (const sentence of text) {
        if (signal.aborted) return;
        if (last !== undefined) send(last, true);
        last = sentence;
      }
      if (!signal.aborted) send(last ?? '', false);
    })();

    const send = (transcript: string, more: boolean) => {
      socket.send(JSON.stringify({
        model_id: model,
        context_id: contextId,
        transcript,
        voice: { mode: 'id', id: voiceId },
        language,
        output_format: { container: 'raw', encoding: 'pcm_s16le', sample_rate: 24000 },
        continue: more,
      }));
    };

    try {
      for (;;) {
        while (queue.length) {
          if (signal.aborted) return;
          yield queue.shift()!;
        }
        if (done) break;
        await new Promise<void>((resolve) => { wake = resolve; });
      }
      await feeding;
      if (failure) throw failure;
    } finally {
      signal.removeEventListener('abort', onAbort);
      try { socket.close(); } catch { /* already closed */ }
    }
  }
}
```

```typescript
import { startup, type Options, type Query, type SDKUserMessage } from '@anthropic-ai/claude-agent-sdk';
import type { AgentEvent, AgentSession, PermissionRequest } from '../types.ts';
import type { Config } from '../config.ts';

const SPOKEN_STYLE = `
Stai parlando a voce, non scrivendo. Frasi brevi, tono naturale, niente elenchi puntati.
Non leggere mai codice ad alta voce: scrivilo e dì "te l'ho scritta".
Accorcia i percorsi dei file. Gli strumenti che hai sono veri: usali davvero.
`.trim();

export function buildOptions(config: Config): Options {
  return {
    model: 'sonnet',
    includePartialMessages: true,
    // All three are required. strictMcpConfig ignores project/user/plugin MCP
    // config; mcpServers leaves nothing to connect; settingSources must be
    // explicit because its default loads everything (spec §12).
    strictMcpConfig: true,
    mcpServers: {},
    settingSources: ['user'],
    allowedTools: [...config.readOnlyTools],
    systemPrompt: { type: 'preset', preset: 'claude_code', append: SPOKEN_STYLE },
    canUseTool: async () => ({
      behavior: 'deny',
      message: 'No spoken-confirmation handler is attached.',
    }),
  };
}

export class ClaudeAgentSession implements AgentSession {
  readonly #config: Config;
  readonly #startupFn: typeof startup;
  #query: Query | undefined;
  #pushTurn: ((text: string) => void) | undefined;
  #handler: ((req: PermissionRequest) => Promise<boolean>) | undefined;
  #pendingNote: string | undefined;

  constructor(config: Config, opts: { startupFn?: typeof startup } = {}) {
    this.#config = config;
    this.#startupFn = opts.startupFn ?? startup;
  }

  async start(): Promise<void> {
    const options: Options = {
      ...buildOptions(this.#config),
      canUseTool: async (toolName, _input, opts) => {
        const summary = (opts as { title?: string }).title ?? `usare ${toolName}`;
        const allowed = await this.handlePermission({ tool: toolName, summary });
        return allowed
          ? { behavior: 'allow' as const, updatedInput: _input }
          : { behavior: 'deny' as const, message: "L'utente non ha confermato a voce." };
      },
    };

    const warm = await this.#startupFn({ options });

    const turns = (async function* (this: ClaudeAgentSession) {
      for (;;) {
        const text = await new Promise<string>((resolve) => { this.#pushTurn = resolve; });
        yield {
          type: 'user' as const,
          message: { role: 'user' as const, content: text },
          parent_tool_use_id: null,
        } satisfies SDKUserMessage;
      }
    }).call(this);

    this.#query = warm.query(turns);
  }

  async *send(text: string): AsyncIterable<AgentEvent> {
    const query = this.#query;
    if (!query) throw new Error('AgentSession.start() must be called before send()');

    const prefixed = this.#pendingNote ? `${this.#pendingNote}\n\n${text}` : text;
    this.#pendingNote = undefined;
    this.#pushTurn?.(prefixed);

    for await (const message of query) {
      if (message.type === 'stream_event') {
        const event = message.event as { type: string; delta?: { type: string; text: string } };
        if (event.type === 'content_block_delta' && event.delta?.type === 'text_delta') {
          yield { type: 'text', delta: event.delta.text };
        }
      } else if (message.type === 'result') {
        yield { type: 'done' };
        return;
      }
    }
  }

  async interrupt(): Promise<void> {
    // NOT abort: aborting tears the session down and takes ~2s (spec §6).
    await this.#query?.interrupt();
  }

  notifyInterruption(spokenSoFar: string, userSaid: string): void {
    this.#pendingNote =
      `[L'utente ti ha interrotto. Ha sentito solo: "${spokenSoFar}". ` +
      `Non dare per scontato il resto della tua risposta.] Ha detto: ${userSaid}`;
  }

  onPermissionRequest(handler: (req: PermissionRequest) => Promise<boolean>): void {
    this.#handler = handler;
  }

  /** Exposed for tests: the timeout is the part that must not regress. */
  async handlePermission(req: PermissionRequest): Promise<boolean> {
    const handler = this.#handler;
    if (!handler) return false;

    // The SDK's permission callback has NO deadline. Without this, a user who
    // walks away leaves the session waiting forever, silently (spec §8).
    let timer: NodeJS.Timeout | undefined;
    const timeout = new Promise<boolean>((resolve) => {
      timer = setTimeout(() => resolve(false), this.#config.director.approvalTimeoutMs);
    });
    try {
      return await Promise.race([handler(req), timeout]);
    } finally {
      clearTimeout(timer);
    }
  }
}
```

Transitions to implement:

| From | Trigger | To | Actions |
|---|---|---|---|
| `LISTENING` | `onSpeechStart` | `HEARING` | open a transcription stream |
| `HEARING` | `onTurnEnd` + non-empty final | `THINKING` | `agent.send()`, start the filler timer |
| `HEARING` | `onTurnEnd` + empty final | `LISTENING` | drop it; a hallucination is not a turn |
| `THINKING` | first speakable sentence | `SPEAKING` | pipe filter → voice → audioOut |
| `THINKING` | `fillerAfterMs` elapsed | `THINKING` | speak one filler line, once per turn |
| `THINKING`/`SPEAKING` | permission request | `AWAITING_APPROVAL` | speak the intent, start the timeout |
| `AWAITING_APPROVAL` | `yes` | back to the previous state | resolve `true` |
| `AWAITING_APPROVAL` | `no` | back to the previous state | resolve `false` |
| `AWAITING_APPROVAL` | `unclear` | `HEARING` | resolve `false`, then re-dispatch the text as a new turn |
| `AWAITING_APPROVAL` | timeout | `LISTENING` | resolve `false`, speak "lascio stare, non ho sentito" |
| `SPEAKING` | `onSpeechStart` | `HEARING` | flush, abort TTS, `agent.interrupt()`, keep `heardMs` |
| `SPEAKING` | `done` | `LISTENING` | — |
| any | audio error | `LISTENING` | speak the error |

Two rules that the tests pin down and that are easy to get wrong:

- **Track the spoken text as it is emitted**, so a barge-in can map `heardMs` back to a
  prefix. Keep a running list of `(sentence, cumulativeMs)` and truncate at `heardMs`.
- **`unclear` is both a denial and a new turn.** Denying without re-dispatching loses what
  the user said, which feels exactly like being ignored.
